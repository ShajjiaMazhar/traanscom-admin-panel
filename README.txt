Traanscom Phase 2 Admin Panel
==============================

This package is styled to match the supplied Traanscom Admin screenshot.

Active features:
- Login/logout
- Dashboard
- Products, search and category filtering
- Add/edit/delete products
- Currency selection by region
- PKR, USD, GBP, EUR, AED, SAR, CAD, AUD, NZD, INR, BDT, TRY
- Currency-aware prices and sale prices
- Real browser image selection with preview and localStorage persistence
- Orders and order-status updates
- Customers
- Store settings
- Responsive layout
